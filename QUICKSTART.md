## 🔑 Get Your API Keys (5 minutes)

### 1️⃣ Google Gemini API
```
URL: https://ai.google.dev/
→ Click "Get API Key"
→ Create project
→ Copy your API key
```

### 2️⃣ Unsplash API (optional, for images)
```
URL: https://unsplash.com/oauth/applications  
→ Register new app
→ Get access key
```

---

## ⚙️ Configure

Open `.env` in project root:

```env
VITE_GEMINI_API_KEY=paste_your_gemini_key_here
VITE_UNSPLASH_API_KEY=paste_your_unsplash_key_here
```

**Save and close!**

---

## 🚀 Run Your App

```bash
npm run dev
```

Look for the **golden ✨ button** in bottom-right corner!

---

## 💡 How to Use

### Click the ✨ Button

#### Tab 1: Create Manual Items
- Enter dish name
- Pick cuisine & category
- Set price
- Generate → Add to Menu

#### Tab 2: Quick Templates
- Click a template (Pakistani, Continental, etc.)
- 3 items auto-generated
- Add all to menu at once
